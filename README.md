# Flow.Launcher.Plugin.Movoa

Unlimited AI video generator with sound: on paid plans the tenth take of a shot costs what the first did, and your first clip is free to make right now. Launch [text to video](https://movoa.ai/video/text-to-video) prompts or submit clips with [native AI audio](https://movoa.ai/video/ai-video-with-audio) directly from Flow Launcher via [Movoa](https://movoa.ai/).

## Usage

- Type `movoa <prompt>` in Flow Launcher.
- Press **Enter** to open the prompt in [Movoa](https://movoa.ai/video/text-to-video), or set `MOVOA_API_KEY` (from [movoa.ai/settings/apikeys](https://movoa.ai/settings/apikeys)) to submit a MiniMax H3 video job directly via the API.
